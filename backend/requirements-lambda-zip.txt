#     (app/mess_extract.py). That module now imports numpy/Pillow in a try/except too, and
#     extract_menu() returns a "not set up on this server" warning instead of crashing the app.
# Both features keep working everywhere else (local dev via requirements.txt, the Docker-based
# deployment path in Dockerfile/Dockerfile.lambda, and the dedicated matcher Lambda in
# Dockerfile.matcher, which already carries its own ML dependencies via requirements-matching.txt).
#

# include; only the four packages above are intentionally dropped.
